## 2. 크몽 상세 분석

### 2-1. 메인 홈 (kmong.com)

**헤더/GNB:**
- 로고 + 검색바(중앙, 넓은 폭) + 로그인/가입
- 카테고리 GNB: 대분류 hover 시 메가메뉴 드롭다운 (2단계 서브카테고리 + 인기 서비스 추천)
- GNB 하단에 "프라임 서비스" 등 프로모션 탭

**히어로 배너:**
- 풀폭 캐러셀, 실제 서비스 관련 고퀄리티 사진/일러스트
- 카테고리별 프로모션 배너 (실사 이미지 + 텍스트 오버레이)
- 자동 슬라이드 + 좌우 화살표 + 하단 dot 인디케이터

**카테고리 섹션:**
- 아이콘 그리드: 각 업종별 고유 일러스트 아이콘 (컬러풀, 둥근 배경)
- "업체 N개" 같은 서브텍스트는 없지만, 아이콘 자체가 직관적

**추천 서비스 카드:**
- 가로 스크롤 캐러셀 (5~6개 노출)
- 카드 구성: 대표 이미지 + 전문가명 + 서비스 제목 + 평점(★) + 리뷰수 + 가격 + "프라임" 뱃지
- 이미지가 실제 포트폴리오/작업물이라서 시각적으로 풍부

**하단 섹션들:**
- "인기 서비스", "최근 본 서비스", "맞춤 추천" 등 개인화 섹션
- 기업 고객/프리랜서 CTA 배너
- 풍부한 푸터: 4컬럼(서비스 소개/고객센터/비즈니스/파트너) + 회사정보 + SNS 링크

### 2-2. 카테고리 리스트 (kmong.com/category/101 - 로고디자인)

**필터 시스템:**
- 좌측 사이드바 필터:
  - 서비스 분류 (로고타입/BI/CI 등 체크박스)
  - 가격대 (슬라이더 + 직접 입력)
  - 작업일 (3일 이내 / 7일 이내 / 14일 이내)
  - 전문가 등급 (프라임 / 전문 / 일반)
  - 만족도 (4.5 이상 / 4.0 이상)
- 상단 정렬: 추천순 / 인기순 / 최신순 / 낮은가격순 / 높은가격순
- 필터 적용 시 결과 카운트 실시간 업데이트

**카드 그리드:**
- 4열 그리드 (데스크톱)
- 카드 구성: 대표 이미지(포트폴리오) + 전문가 아바타 + 이름 + 서비스 제목 + 평점 + 리뷰수 + 가격 + 뱃지
- 그리드뷰/리스트뷰 토글 지원

### 2-3. 서비스 상세 (kmong.com/gig/428244 - 로고디자인 브랜드평판1위)

**히어로 영역 (상단):**
- 좌: 이미지 캐러셀 (5~10장, 실제 포트폴리오 이미지)
  - 메인 이미지 크게 + 하단 썸네일 리스트
  - 클릭 시 라이트박스 전체화면
- 우: 서비스 정보 패널
  - "프라임" 뱃지 (파란색 체크)
  - 전문가 프로필: 아바타 + 이름 + "top 2%" 뱃지
  - 응답시간: "평균 1시간 이내"
  - 평점 ★4.9 (리뷰 1,234건)
  - 가격 탭: STANDARD(15만) / DELUXE(25만) / PREMIUM(40만)
  - 각 티어별 포함 항목 리스트
  - "구매하기" Primary 버튼 + "문의하기" Secondary 버튼

**Sticky 가격 패널:**
- 스크롤 시 우측에 가격 패널이 sticky로 고정
- 항상 가격 + CTA 버튼이 보이는 구조

**탭 네비게이션:**
- 서비스 설명 | 포트폴리오 | 가격표 | 전문가 정보 | 리뷰
- 스크롤 위치에 따라 탭 자동 활성화 (scroll spy)
- 탭 클릭 시 해당 섹션으로 부드러운 스크롤

**포트폴리오 탭:**
- 이미지 그리드 (3열, 86개 항목)
- 클릭 시 모달로 확대
- "더보기" 버튼으로 점진적 로딩

**서비스 설명 탭:**
- 리치 콘텐츠: 이미지 삽입, 볼드/컬러 텍스트, 구분선
- 실제 작업 사례 이미지 다수 포함
- 서비스 옵션 태그: "로고타입", "워드마크", "심볼+워드마크" 등

**가격 정보 탭:**
- 3단 비교 테이블 (STANDARD / DELUXE / PREMIUM)
- 각 티어별: 가격, 작업일, 수정횟수, 포함항목 체크리스트
- 추가 옵션별 가격 리스트

**리뷰 탭:**
- 상단 요약:
  - 전체 평점 ★4.9 크게 표시
  - 항목별 평점 막대그래프: 결과물 만족도 / 친절한 상담 / 신속한 대응
  - 5점/4점/3점/2점/1점 비율 분포 바
- AI 리뷰 요약: "최근 리뷰를 분석한 결과..." 키워드 추출
- 개별 리뷰:
  - 리뷰어 아바타 + 닉네임 + 날짜
  - 별점 + 텍스트
  - 사진 리뷰: 첨부 이미지 썸네일 (클릭 확대)
  - **전문가 답변**: 리뷰 하단에 전문가가 답글 작성 가능
- 필터: 최신순 / 평점높은순 / 평점낮은순 / 사진리뷰만
- "사진 리뷰" 별도 섹션 (사진만 모아보기)

**리뷰 섹션:**
