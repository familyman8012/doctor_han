## Phase 3. 베타 오픈

**기간**: 4월 10일 (목) ~ 4월 24일 (목)
**담당**: 운영 대표 (운영) + 개발자 (모니터링/긴급 수정)

### 베타 운영 목표
- 소수 업체(5~10개)를 초대하여 실제 서비스 사용
- 실 사용 데이터로 과금/정산 플로우 검증
- 사용자 피드백 수집 → 개선 사항 반영

| 주차 | 할 일 |
|------|------|
| 4/10~4/16 | 베타 업체 초대 (기존 네트워크), 업체 온보딩 지원, 리드 테스트 |
| 4/17~4/24 | 실 사용 피드백 수집, 긴급 버그 수정, UX 개선, TossPayments 심사 결과 반영 |

**모니터링 항목**:
- Sentry 에러 로그 일일 점검
- 리드 발생/응답률 확인 (관리자 대시보드)
- 크레딧 충전/차감 정상 동작 확인
- 이메일/알림톡 발송 정상 확인

**완료 기준**:
- TossPayments 라이브 키 적용 완료
- 베타 업체 최소 5개 정상 운영 확인
- 크리티컬 버그 0건
