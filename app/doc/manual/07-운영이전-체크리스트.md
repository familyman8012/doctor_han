# 운영 이전 체크리스트

> 개발자(윤은석) → 운영 대표에게 메디허브 플랫폼을 완전히 이전하기 위한 체크리스트입니다.
> 각 항목은 **계정 소유자를 대표 명의로 전환**하고, **유료 플랜으로 업그레이드**하는 과정을 포함합니다.

## 1. 도메인 구매 및 DNS 설정

### 할 일
- [ ] 도메인명 확정 (예: `medihub.kr`, `medihub.co.kr`, `medi-hub.kr` 등)
- [ ] 도메인 구매 (가비아, 카페24, Cloudflare 등)
- [ ] DNS 설정:
  - [ ] Vercel 커스텀 도메인 연결 (CNAME → `cname.vercel-dns.com`)
  - [ ] 이메일 발송용 도메인 인증 (Resend DKIM/SPF 레코드 추가)
- [ ] SSL 인증서 (Vercel 자동 발급)

### 영향 범위
- `NEXT_PUBLIC_SITE_URL` → 새 도메인으로 변경
- Supabase Auth Redirect URL → 새 도메인 추가
- 카카오/Google OAuth Redirect URI → 새 도메인 추가
- TossPayments 웹훅 URL → 새 도메인으로 변경

- [ ] **방법 B**: 새 앱 생성 (권장 — 사업자 인증까지 한번에)
  - [ ] 앱 생성 → **비즈 앱 전환** (사업자등록증 제출)
  - [ ] 동의항목 설정: 이메일 수집 동의 (비즈 앱 필수)
  - [ ] 플랫폼 등록: 웹 사이트 도메인

- [ ] 환경 변수 교체:
  - `KAKAO_REST_API_KEY` → 새 REST API 키
  - `NEXT_PUBLIC_KAKAO_MAP_KEY` → 새 JavaScript 키
- [ ] Supabase Auth > Kakao Provider 키 교체

**5-2. 카카오 채널 (알림톡용)**
- [ ] 대표 명의로 [카카오비즈니스](https://business.kakao.com/) 채널 생성

- Google Cloud Console > APIs & Services > Credentials

### 할 일
- [ ] **방법 A**: 기존 프로젝트에 대표 Google 계정을 Owner로 추가
- [ ] **방법 B**: 새 GCP 프로젝트 생성
  - [ ] OAuth 동의 화면 설정 (앱 이름, 로고, 도메인)
  - [ ] OAuth 2.0 Client ID 생성
  - [ ] Redirect URI: `https://[Supabase프로젝트].supabase.co/auth/v1/callback`
  - [ ] Client ID / Client Secret 발급
- [ ] Supabase Auth > Google Provider 키 교체

> Google OAuth는 "테스트" 모드에서는 등록된 테스트 사용자만 로그인 가능. "프로덕션"으로 전환하려면 **OAuth 동의 화면 인증(앱 확인)** 필요 — 개인정보 처리방침 URL, 홈페이지 URL 등 제출.
