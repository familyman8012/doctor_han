## 1. 시스템 개요

### 1.1 메디허브란?

**메디허브 = 의료인과 의료산업 업체를 연결하는 B2B 마켓플레이스**

쉽게 말해 **"의료계의 크몽"** 입니다.
한의사가 병원을 개원하거나 운영할 때 필요한 업체(원외탕전, 의료기기, 인테리어, 마케팅 등)를 검색하고, 비교하고, 문의할 수 있는 플랫폼입니다.

### 1.2 왜 필요할까요?

일반 소비자 서비스(B2C)와 의료 B2B는 완전히 다른 특성을 가지고 있습니다.

| 구분 | 일반 소비자 (B2C) | 의료 B2B |
|------|-------------|---------|
| 정보 | 네이버 검색하면 나옴 | 지인 소개, 커뮤니티 질문에 의존 |
| 비교 | 가격비교 사이트 다수 | 업체별 비교할 방법이 없음 |
| 신뢰 | 리뷰/별점으로 판단 | 검증된 리뷰 시스템 부재 |
| 견적 | 정가 결제 | 업체마다 가격이 다름, 협상 필요 |
| 업종 | 단일 분야 | 의료기기, 인테리어, 세무, 마케팅 등 다양 |

이러한 의료 B2B의 정보 파편화, 신뢰 부재, 비효율적 소통을 해결하기 위해 메디허브가 필요합니다.

### 1.3 메디허브가 관리하는 영역

```
메디허브가 하는 일들
├── 업체 정보        무엇을 제공하는지, 어디서, 얼마에
├── 업체 인증        믿을 수 있는 업체인지 검증
├── 문의(리드) 관리   한의사 → 업체 문의 접수 및 응답
├── 리뷰/평판        실 이용자의 리뷰로 신뢰 확보
├── 과금/결제        크레딧 기반 업체 과금 시스템
├── 광고             배너 + 우선순위 노출
└── 정산             업체별 월간 정산
```

## 2. 핵심 도메인 개념

### 2.1 3가지 역할

메디허브에는 **3가지 역할**이 있고, 각각 보는 화면과 할 수 있는 일이 다릅니다.

```
┌──────────┐     ┌──────────┐     ┌──────────┐
│  한의사    │     │   업체    │     │  관리자   │
│ (Doctor)  │     │ (Vendor) │     │ (Admin)  │
├──────────┤     ├──────────┤     ├──────────┤
│ 업체 검색  │     │ 리드 응답  │     │ 인증 승인  │
│ 문의 생성  │     │ 상품 등록  │     │ 사용자 관리│
│ 리뷰 작성  │     │ 크레딧 충전│     │ 정산 관리  │
│ 찜/비교   │     │ 광고 구매  │     │ 통계/리포트│
└──────────┘     └──────────┘     └──────────┘
```

### 2.2 병원 개원 비유로 이해하기

**상황**: 여러분이 한의원을 개원한다고 가정해봅시다.

| 메디허브 개념 | 현실 비유 | 설명 |
|---------|-------|------|
| **업체** | 인테리어 업자, 의료기기 대리점 | 서비스를 제공하는 파트너 |
| **카테고리** | 업종 분류표 | 원외탕전, 의료기기, 인테리어 등 |
| **문의(리드)** | "견적 좀 보내주세요" 전화 | 한의사가 업체에 보내는 문의 |
| **크레딧** | 업체가 충전해 쓰는 포인트 | 리드 수신, 광고 등에 사용 |
| **서비스 단가** | "문의 1건당 얼마" | 카테고리별 리드 수신 비용 |
| **구독** | "월정액 무제한 요금제" | 기간 내 리드 무제한 수신 |
| **입점 멤버십** | "연회비" | S등급 업종 연간 입점비 |

### 2.3 핵심 엔티티 6가지

메디허브의 핵심은 **6개의 엔티티**가 연결되는 구조입니다:

```
┌────────┐    ┌────────┐    ┌────────┐
│ 한의사   │───→│  리드   │───→│  업체   │
│(의료인)  │    │ (문의)  │    │(파트너) │
└────────┘    └────────┘    └────────┘
                  │               │
                  ▼               ▼
             ┌────────┐    ┌────────┐
             │  리뷰   │    │ 크레딧  │
             │ (평가)  │    │ (과금)  │
             └────────┘    └────────┘
                               │
                               ▼
                          ┌────────┐
                          │  정산   │
                          │ (월간)  │
                          └────────┘
```

### 2.4 왜 이렇게 나뉘어 있을까요?

"그냥 업체 목록 보여주고 전화번호 주면 되는 거 아닌가요?" 라고 생각할 수 있지만, 그렇게 단순하지 않습니다.

1. **같은 업체라도 서비스마다 가격이 다릅니다**
   - A업체: 의료기기 리드 → 15만원
   - A업체: 마케팅 리드 → 5만원
   - → 카테고리별 **서비스 단가** 관리가 필요

2. **문의만 하고 안 쓰는 경우도 있습니다**
   - 한의사가 문의만 하고 계약하지 않을 수 있음
   - → **리드 상태 관리** (신청 → 진행 → 완료/취소)가 필요

3. **업체가 응답하지 않을 수도 있습니다**
   - 48시간 무응답 → 경고
   - 72시간 무응답 → 크레딧 자동 복구
   - → **SLA 관리**와 **자동화**가 필요

4. **허위 문의가 올 수도 있습니다**
   - 장난 전화 같은 허위 리드 → 업체 신고 → 관리자 심사 → 환불
   - → **신고/환불 시스템**이 필요

## 3. 엔티티 상세 설명

### 3.1 리드 (Lead) — 문의

#### 한 줄 요약

> "한의사가 업체에 보내는 문의" — 메디허브의 핵심 거래 단위

#### 왜 '리드'라고 부를까요?

마케팅 용어로 **리드(Lead)** = "잠재 고객의 문의". 업체 입장에서 한의사의 문의는 곧 잠재적 계약으로 이어질 수 있는 소중한 기회이므로 리드라고 부릅니다.

#### 리드 구조

```
리드 (Lead)
├── 기본 정보
│   ├── 문의자: 한의사 1 (doctor1@medihub.local)
│   ├── 수신 업체: 온의료기기 웍스
│   ├── 관심 서비스: 의료기기 (진단장비)
│   └── 문의 내용: "혈액검사기 도입 문의드립니다..."
│
├── 연락 정보
│   ├── 이름 / 연락처 / 이메일
│   ├── 소속 / 직책
│   └── 선호 연락 방법 / 시간
│
├── Q&A 스레드
│   ├── 업체 → 한의사: "어떤 검사 항목이 필요하신가요?"
│   └── 한의사 → 업체: "CBC, 간기능, 신기능이요"
│
├── 과금 정보
│   ├── 차감 크레딧: 15만원 (의료기기 카테고리 단가)
│   └── 과금 상태: 차감완료 / 복구 / 무료(구독)
│
└── 첨부 파일
    └── 도면.pdf, 사업자등록증.pdf
```

#### 리드 상태 흐름

```
신청완료 → 진행중 → 견적대기 → 협의중 → 계약 → 완료
                                        ↘ 보류
                                        ↘ 취소
```

| 상태 | 설명 | 누가 변경? |
|------|------|---------|
| **신청완료** | 한의사가 문의를 보냄 | 시스템 |
| **진행중** | 업체가 리드를 확인하고 응답 시작 | 업체 |
| **견적대기** | 업체가 견적을 제출함 | 업체 |
| **협의중** | 한의사와 업체가 조건 협의 중 | 업체 |
| **계약** | 계약 체결 | 업체 |
| **완료** | 거래 종료 | 업체/시스템 |
| **취소** | 한의사가 문의 취소 | 한의사 |
| **보류** | 일시 보류 | 업체 |

### 3.2 크레딧 (Credit) — 가상화폐

#### 한 줄 요약

> "업체가 충전해서 쓰는 선불 포인트" — 리드 수신, 광고, 구독 등의 결제 수단

#### 왜 필요할까요?

업체가 리드를 받을 때마다 매번 카드 결제하면 불편합니다. 미리 크레딧을 충전해두면:
- 리드 수신 시 자동 차감 (매번 결제 불필요)
- 광고 구매, 구독 구매도 크레딧으로 한번에
- 무응답/허위 리드 시 자동 복구 가능

#### 크레딧 흐름

```
충전 (TossPayments 카드 결제)
    │
    ▼
크레딧 잔액 증가 (+10만원)
    │
    ├── 리드 수신 → 자동 차감 (-5만원)
    ├── 광고 구매 → 차감 (-30만원)
    ├── 구독 구매 → 차감 (-50만원)
    ├── 입점비 납부 → 차감 (-200만원)
    │
    ├── 무응답 72h → 자동 복구 (+5만원)
    ├── 허위 리드 승인 → 복구 (+5만원)
    └── 관리자 수동 지급 → 증가 (+10만원)
```

#### 핵심 정책

| 항목 | 정책 |
|------|------|
| 유효기간 | 충전일로부터 **12개월** |
| 자동충전 | 설정 가능 (잔액 부족 시 자동) |
| 자동충전 보너스 | **2% 추가** 지급 |
| 잔액 부족 시 | 리드 소프트 거절 + 충전 안내 알림 |

### 3.3 서비스 단가 — 카테고리별 리드 가격

#### 한 줄 요약

> "이 카테고리로 문의가 오면 얼마를 받겠다" — 업체가 직접 설정하는 리드 단가

#### 비유로 이해하기

음식 배달앱에서 가게 사장님이 "배달비 3,000원"을 설정하는 것과 비슷합니다.
메디허브에서는 업체가 "의료기기 문의 1건당 15만원"처럼 설정합니다.

```
업체: 온의료기기 웍스
├── 의료기기 (진단장비)  → 15만원/건
├── 의료기기 (치료장비)  → 12만원/건
└── 의료기기 (소모품)    → 3만원/건
```

> 단가를 설정하지 않은 카테고리로는 리드를 받을 수 없습니다.

### 3.4 구독 — 기간제 무제한

#### 한 줄 요약

> "이 기간 동안 이 카테고리 리드는 무료로 받겠다" — 건별 과금 면제

#### 건별 과금 vs 구독

| | 건별 과금 (CPL) | 구독 |
|---|---|---|
| 결제 | 리드 1건마다 크레딧 차감 | 기간 시작 시 일시불 |
| 적합한 경우 | 리드가 적은 카테고리 | 리드가 많은 카테고리 |
| 장점 | 쓴 만큼만 지불 | 예측 가능한 비용 |
| 단점 | 리드 많으면 비쌈 | 리드 적으면 손해 |

### 3.5 광고 — 우선순위 노출

#### 한 줄 요약

> "카테고리 페이지 상단에 내 업체를 노출시키는 유료 서비스"

#### 4등급 체계

```
카테고리 페이지 상단
┌─────────────────────────────────────┐
│ 1줄: 프리미엄 (30만/주)  ← 최상단      │
│ 2줄: 플러스업 (21만/주)               │
│ 3줄: 플러스 (6만/주)                  │
│ 4줄: 루키 (3만/주) + 점프업 3회        │
├─────────────────────────────────────┤
│ 일반 업체 목록 (추천순/평점순 등)        │
└─────────────────────────────────────┘
```

**루키 점프업**: 루키 등급 구매 시 기간 내 3회, 30분간 프리미엄 위 최상단에 노출되는 부스트 기능

## 4. 비즈니스 흐름 (End-to-End)

### 4.1 일반 리드 흐름

전체 프로세스를 처음부터 끝까지 따라가 보겠습니다.

**시나리오: 한의사 김한방이 의료기기 업체에 문의하기**

```
[STEP 1] 업체 탐색 (한의사)
─────────────────────────
한의사 김한방이 혈액검사기를 알아봅니다.

메디허브 접속 → 카테고리 "의료기기" 클릭
→ 필터: 지역 "서울", 평점 4.0 이상
→ 업체 목록에서 "온의료기기 웍스" 클릭
→ 상세 페이지에서 포트폴리오, 리뷰, 가격 확인

          │
          ▼

[STEP 2] 문의 생성 (한의사)
─────────────────────────
"문의하기" 버튼 클릭 → 문의 양식 작성

┌─────────────────────────────┐
│ 관심 서비스: 의료기기 (진단장비) │
│ 이름: 김한방                   │
│ 연락처: 010-1234-5678         │
│ 문의 내용: "혈액검사기 도입..."  │
│ 첨부: 병원도면.pdf              │
└─────────────────────────────┘

→ 문의 제출!

          │
          ▼

[STEP 3] 리드 수신 + 크레딧 차감 (시스템)
─────────────────────────────────────
시스템이 자동으로:
1. 업체의 서비스 단가 확인 (의료기기: 15만원)
2. 업체 크레딧에서 15만원 차감
3. 업체에 알림 발송 (이메일 + 카카오 알림톡)
4. 리드 상태: "신청완료"

          │
          ▼

[STEP 4] 리드 확인 + 응답 (업체)
───────────────────────────────
업체 담당자가 파트너센터 > 받은 리드함에서 확인

- 리드 상태를 "진행중"으로 변경
- Q&A 스레드에서 추가 질문:
  "어떤 검사 항목이 필요하신가요?"

→ 한의사에게 알림 발송

          │
          ▼

[STEP 5] 소통 + 견적 (업체 ↔ 한의사)
────────────────────────────────────
Q&A 스레드에서 대화 진행

업체: "CBC 분석기 기준 견적 드립니다"
→ 견적서.pdf 첨부
→ 리드 상태: "견적대기"

한의사: "감사합니다, 검토해보겠습니다"
→ 리드 상태: "협의중"

          │
          ▼

[STEP 6] 거래 완료 또는 취소
──────────────────────────
케이스 A: 계약 체결
  → 리드 상태: "계약" → "완료"
  → 한의사가 리뷰 작성 가능

케이스 B: 불발
  → 리드 상태: "보류" 또는 "취소"
```

### 4.2 무응답 리드 흐름

업체가 응답하지 않는 경우의 자동 처리 흐름입니다.

```
리드 수신 (크레딧 15만원 차감)
    │
    │  48시간 경과, 업체 무응답
    │
    ▼
시스템: 카카오 알림톡 발송
"[메디허브] 48시간 내 미응답 리드가 있습니다.
 72시간 초과 시 크레딧이 자동 복구됩니다."
    │
    │  24시간 추가 경과 (총 72시간)
    │
    ▼
시스템: 자동 크레딧 복구 (+15만원)
→ 리드 종료
→ 업체에 복구 알림 발송
```

### 4.3 허위 리드 신고 흐름

```
업체: "이 리드는 허위입니다" (신고 제출)
    │
    ▼
관리자: 신고 접수 → 심사
    │
    ├── 승인: 크레딧 복구 (+15만원)
    │         → 업체에 복구 알림
    │
    └── 거절: 거절 사유와 함께 통보
              → 크레딧 변동 없음
```

### 4.4 인테리어 비딩 흐름

일반 카테고리와 달리 인테리어는 **비딩(입찰)** 방식으로 운영됩니다.

```
[STEP 1] 프로젝트 등록 (한의사)
──────────────────────────────
"한의원 30평 인테리어, 예산 5천만원, 강남"

          │
          ▼

[STEP 2] 자동 매칭 (시스템)
──────────────────────────
스코어링 기준:
├── 지역 일치    30%
├── 평점         25%
├── 응답률       20%
├── 포트폴리오   15%
└── 가격 적합도  10%

→ 상위 3개 업체 선정 → 입찰 요청 발송

          │
          ▼

[STEP 3] 견적 제출 (업체들)
──────────────────────────
업체 A: 4,800만원, 8주 소요
업체 B: 5,200만원, 6주 소요
업체 C: 4,500만원, 10주 소요

          │
          ▼

[STEP 4] 업체 선정 (한의사)
──────────────────────────
견적 비교 → 업체 A 선정

          │
          ▼

[STEP 5] 계약 + 수수료 (시스템)
──────────────────────────────
계약 금액의 3% = 144만원 수수료
```

## 6. 수익 모델과 과금 체계

### 6.1 수익원 6가지

메디허브는 **6가지 방식**으로 수익을 만듭니다.

```
수익 구조
├── 1. 입점 멤버십 (S등급 연 200만원)
│     └── 대상: 원외탕전(한약/약침), 약재회사 (~295개 업체)
│
├── 2. 리드 과금 CPL (건별 1~20만원)
│     └── 문의 1건마다 업체 크레딧 차감
│
├── 3. 기간제 구독 (30~365일)
│     └── 구독 기간 내 해당 카테고리 리드 무료
│
├── 4. 배너 광고 (메인 200만/월, 서브 120만/월)
│     └── 메인 페이지 배너 슬롯
│
├── 5. 우선순위 노출 (주 3~30만원)
│     └── 카테고리 페이지 상단 4줄 광고
│
└── 6. 비딩 수수료 (계약의 3%)
      └── 인테리어 비딩 계약 시 수수료
```

### 6.2 과금 흐름 요약

```
업체가 크레딧 충전 (TossPayments)
         │
         ▼
    ┌─────────┐
    │ 크레딧   │──── 리드 수신 시 자동 차감
    │  잔액    │──── 구독 구매 시 차감
    │         │──── 광고 구매 시 차감
    │         │──── 입점비 납부 시 차감
    │         │
    │         │◄─── 무응답 72h 자동 복구
    │         │◄─── 허위 리드 심사 후 복구
    │         │◄─── 관리자 수동 지급 (보상)
    └─────────┘
         │
         ▼ (월말)
    ┌─────────┐
    │  정산    │──── 업체별 월간 정산 생성
    │         │──── 관리자 검토 → 승인 → 지급
    └─────────┘
```

### 6.3 S등급 업종이란?

S등급 업종은 시장 규모가 크고 거래 금액이 높은 핵심 업종입니다.

| S등급 업종 | 예상 업체 수 | 입점비 |
|---------|---------|------|
| 원외탕전 (한약) | ~120개 | 연 200만원 |
| 원외탕전 (약침) | ~25개 | 연 200만원 |
| 약재회사/제약사 | ~150개 | 연 200만원 |

**미납 시**: 기본 입점은 가능하지만, 검색 하위 노출 + 리드 수신 차단

## 9. FAQ

### 자주 묻는 질문

**Q: 한의사가 문의하면 업체에 바로 전화번호가 공개되나요?**

A: 네, 한의사가 문의 양식에 입력한 연락처가 업체에 전달됩니다. 이것이 업체가 크레딧을 지불하는 이유입니다 — 검증된 잠재 고객의 연락처를 얻는 것입니다.

**Q: 업체가 크레딧이 없으면 리드를 못 받나요?**

A: 네, 크레딧 잔액이 서비스 단가보다 적으면 리드가 소프트 거절됩니다. 한의사에게는 다른 업체가 안내되고, 업체에게는 충전 안내 알림이 발송됩니다.

**Q: 구독 중이면 리드가 완전 무료인가요?**

A: 네, 구독 중인 카테고리로 들어오는 리드는 크레딧 차감 없이 무료입니다. 구독 기간이 끝나면 건별 과금으로 자동 전환됩니다.

**Q: 같은 한의사가 같은 업체에 여러 번 문의하면 매번 과금되나요?**

A: 아닙니다. 30일 이내 동일 한의사→동일 업체 문의는 **중복 리드**로 판정되어 무료 처리됩니다.

**Q: 업체가 응답 안 하면 한의사는 어떻게 되나요?**

A: 48시간 미응답 시 업체에 경고 알림이 가고, 72시간이 지나면 업체의 크레딧이 자동 복구됩니다. 한의사에게는 다른 업체를 추천하는 안내가 갑니다.

**Q: 인증을 안 해도 서비스를 쓸 수 있나요?**

A: 기본적인 업체 검색/조회는 가능하지만, 문의 생성(한의사)이나 리드 수신(업체)은 인증 완료 후에만 가능합니다.

**Q: 배너 광고와 우선순위 광고의 차이는?**

A: **배너 광고**는 메인 페이지 상단에 이미지 배너가 노출되는 것이고, **우선순위 광고**는 카테고리 페이지에서 업체가 상단에 노출되는 것입니다. 배너는 관리자가 등록하고, 우선순위는 업체가 직접 구매합니다.

**Q: S등급 업종인데 입점비를 안 내면?**

A: 기본 입점은 가능하지만 검색 결과 하위 노출 + 리드 수신이 차단됩니다. 연회비(200만원)를 납부하면 모든 기능이 열립니다.

**Q: 정산은 어떻게 되나요?**

A: 월말에 업체별 정산이 생성되고, 관리자가 검토 → 승인 → 지급 처리합니다. 초기에는 정산서 확인 후 수동 이체로 진행합니다.

**Q: 비딩(인테리어)은 다른 카테고리에도 적용되나요?**

A: 현재는 인테리어 카테고리에만 비딩이 적용됩니다. 다른 카테고리는 일반 리드(문의) 방식입니다. 향후 수요에 따라 확대될 수 있습니다.
