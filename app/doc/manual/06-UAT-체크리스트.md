# 인수 테스트 (UAT) 체크리스트

> 테스터는 3가지 역할(한의사/업체/관리자)로 각각 로그인하여 전체 플로우를 순서대로 진행합니다.

## 기록 방법

각 항목을 테스트한 후 결과를 기록합니다:

- `[P]` **Pass** — 정상 동작
- `[F]` **Fail** — 버그 또는 오류 (구체적 증상 기록)
- `[I]` **Improvement** — 동작은 하지만 개선이 필요 (UX/UI 불편 등)
- `[S]` **Skip** — 테스트 불가 (환경 제약, 데이터 부족 등)

**기록 예시:**
```
- [P] 1-1. 메인 페이지 접속
- [F] 1-3. 검색 결과 — "의료기기" 검색 시 결과 0건 표시됨 (업체가 있는데 안 나옴)
- [I] 2-3. 문의 양식 — 연락처 입력 시 하이픈 자동 포맷이 없어서 불편
```
