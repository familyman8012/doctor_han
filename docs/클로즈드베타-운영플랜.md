| 목표 | 리드 흐름 정상 작동 검증, 치명적 오류 제거, 1군 업체 선별 |

## 2. 업체 크레딧 정책

| 시점 | 내용 |
|------|------|
| 시작 시 | 테스트 크레딧 **100,000원** 지급 |
| 2주 종료 후 조건 충족 시 | 추가 크레딧 **150,000원** 지급 |

### 추가 지급 조건

- 리드 응답률 80% 이상
- 평균 응답시간 24시간 이내
- 최소 1회 인터뷰 참여
- 베타 정책 위반 없음

---

## 3. 의료인 참여 조건

- 최소 3~5건 이상 문의 생성
- 실제 수요 기반 문의 권장
- 베타 종료 후 간단 피드백 설문 참여

- [ ] 동시 다중 문의 생성 테스트
- [ ] 동일 의료인 다중 문의 테스트

- [ ] 문자 누락 여부 매일 확인
- [ ] 리드 상태 변경 오류 여부 확인
- [ ] 관리자 통계 수치 정확성 확인

### 매일 점검 항목

- 문자 발송 성공 여부

- 미열람 리드 수

## 7. 베타 성공 기준

| 지표 | 기준 |
|------|------|
| 총 리드 | 50건 이상 |
| 평균 응답률 | 70% 이상 |
| 상위 5개 업체 응답률 | 90% 이상 |
| 치명적 버그 | 0건 |
| 의료인 재사용 의향 | 60% 이상 |

---

## 8. 1군 업체 선별 기준 (A/B/C 등급)

| 등급 | 조건 |
|------|------|
| **A** | 응답률 80%+, 평균 응답시간 12~24h, 분쟁 없음, 피드백 적극 참여 |
| **B** | 응답률 60~80% |
| **C** | 응답률 60% 미만, 미열람 반복 |

---

## 9. 관리자 일일 점검 항목

- 리드 생성 건수
- 업체별 응답률
- 평균 응답시간
- 미열람 24시간 이상 리드 수
- 문자 발송 실패 로그
- 상태 변경 누락 여부
- DB 기록 정상 저장 여부

---

## 10. 절대 발생하면 안 되는 오류

- 리드 생성됐는데 업체 문자 미수신
- 리드 상태 사라짐
- 점수 잘못 차감
- 업체 간 리드 정보 노출
- 관리자도 원인 추적 불가
